3 Mode Pembuatan Dokumen

Template + Parameter: Auto-generate dari tag/placeholder. Edit Online: Langsung di browser. Upload Manual: File dari komputer lokal.

Editor Kolaboratif Real-Time

OnlyOffice terintegrasi — edit DOCX, XLSX, PPTX langsung di browser. Track Changes, co-editing multi-user, comment, dan auto-save.

Workflow Multi-Level

Review → approval bertingkat berbasis hirarki organisasi. SLA per langkah, eskalasi otomatis, delegasi, parallel approval, dan routing penolakan fleksibel.

Tanda Tangan Elektronik (TTE)

Digital signature berbasis SHA-256 dengan verifikasi integritas dokumen. Siap integrasi PSrE (Privy, VIDA, Peruri) untuk sertifikasi resmi.

OCR — Ekstraksi Teks

Tesseract engine untuk ekstraksi teks dari scan PDF dan gambar. Mendukung Indonesia + Inggris. Hasil terintegrasi ke full-text search.

Distribusi & Acknowledge

Distribusikan dokumen final ke penerima individual atau bulk. Lacak status: pending, terkirim, dikonfirmasi — secara real-time.

Watermark Otomatis

Watermark on-the-fly saat preview dan download berdasarkan klasifikasi (Rahasia/Internal/Publik). File asli tetap bersih di storage.

Versioning Lengkap

Major/minor version otomatis. Setiap versi tersimpan permanen — restore satu klik, compare antar versi. Lock otomatis setelah final approval.

SLA Monitoring

Tracking waktu per langkah workflow. Dashboard SLA compliance, breach alert, eskalasi otomatis ke atasan, dan reminder sebelum deadline.

Kenapa Beralih dari DMS Konvensional?

Perbandingan langsung antara DMS konvensional (M-Files, SharePoint, dll.) dengan solusi kami.

Fitur DMS Konvensional DMS Kami
Lisensi User Per-seat (mahal, terbatas) ✓ Unlimited user
Edit Dokumen Install plugin desktop ✓ Langsung di browser
Co-editing Terbatas / tidak ada ✓ Real-time multi-user
Template Copy file, edit manual ✓ Auto-generate dari parameter
Watermark Manual atau plugin ✓ Otomatis per klasifikasi
Versioning Otomatis saat save ✓ Major/minor + lock final
TTE Tidak ada / manual ✓ Terintegrasi + PSrE-ready
Workflow Statis / terbatas ✓ Dinamis + SLA + eskalasi
Role & Permission Fixed roles ✓ Kustom + data scope
Kepemilikan Data Vendor / cloud asing ✓ Self-hosted, DC Indonesia
Integrasi ERP Add-on berbayar ✓ API-first, siap integrasi
